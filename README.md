# CS50x Harvard - Computer Science Log

A public log focused on core computer science fundamentals, data structures, algorithm design and system architecture.

## Course Overview
This repository documents my progression through Harvard University's CS50x curriculum, tracking theoretical insights and programmatic problem solving workflows.

### Core Concepts Learned
* Data Representation: Analyzed how hardware utilizes transistors to store information in binary format (0s and 1s). Studied mapping mechanics including ASCII and Unicode for characters, and RGB values for images.
* Algorithmic Efficiency: Examined algorithmic thinking through step by step problem solving. Explored optimization concepts by analyzing how binary search improves look up times compared to linear execution methods.
* Control Structures: Studied standard programmatic flows such as loops, conditional statements, variables, and event driven architecture.

### Problem Solving & Implementation
* System Design: Developed an interactive Automated Teller Machine (ATM) transaction simulator to practice data control structures.
* Logic & Validation: Built conditional rules to handle balance changes and created validation checks to reject wrong PINs or invalid actions.
